# Day3 - 반응형 이력서 업데이트

## 핵심 변경 요약

| 항목 | 변경 내용 |
|------|-----------|
| **navbar** | 사이드바 navbar 추가 (데스크톱 고정 / 모바일 슬라이드) |
| **반응형** | 1024px / 768px / 480px 3단계 미디어쿼리 |
| **flex** | 헤더, 경력 정보, 스킬 태그에 flex 적용 |
| **모바일 UX** | 햄버거 버튼 + 오버레이로 사이드바 열고 닫기 |
| **표 반응형** | 768px 이하에서 표를 카드형(스택형) 레이아웃으로 전환 |
| **Skills** | 기존 리스트 → 카테고리별 flex 태그로 시각화 |
| **Experience** | 경력 정보를 flex로 정리, 프로젝트 상세 리스트 유지 |
| **디자인 유지** | 기존 네이비/블루 포인트 컬러 및 카드형 레이아웃 유지 |
