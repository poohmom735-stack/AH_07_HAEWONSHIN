# HTML 핵심 태그 개념 및 실습 정리

오늘 학습한 핵심 HTML 태그들의 역할과 언제 사용하는지 정리하고, 실제 웹페이지 구조를 짜기 위한 실습 예제 코드를 기록합니다.

---

## 1. 문서의 기본 구조를 잡는 태그

###  `<head>`
*   **개념:** 웹 브라우저 화면에는 직접 보이지 않지만, 웹페이지를 구동하는 데 필요한 **설정 데이터(메타데이터)**를 담는 공간입니다.
*   **주요 역할:** 문서의 제목 지정, 인코딩 설정(`UTF-8`), 외부 CSS 및 JavaScript 파일 연결 등.

###  `<body>`
*   **개념:** 사용자의 눈에 실제로 보이는 **웹페이지의 모든 본문 콘텐츠**가 들어가는 핵심 영역입니다.
*   **주요 역할:** 텍스트, 이미지, 표, 버튼, 입력창 등 실질적인 인터페이스 요소를 배치합니다.

 **구조 실습 예제:**
```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>내 정보 페이지</title>
</head>
<body>
    <p>여기에 작성하는 내용만 실제 웹 화면에 노출됩니다.</p>
</body>
</html>
```

---

## 2. 텍스트를 구조화하는 태그

### `<p>` (Paragraph)
*   **개념:** 하나의 독립된 **글 문단**을 선언할 때 사용합니다.
*   **주요 역할:** 문단과 문단 사이에 자연스러운 여백(Margin)을 자동으로 만들어주며, 문단이 끝나면 자동으로 줄바꿈이 일어납니다.

 **텍스트 실습 예제:**
```html
<p>첫 번째 문단입니다. 자기소개 글의 도입부를 여기에 작성합니다.</p>
<p>두 번째 문단입니다. 자연스럽게 위 문단과 위아래 공백이 생기며 구별됩니다.</p>
```

## 3. 목록(List)을 만드는 태그

###  `<ul>` (Unordered List)
*   **개념:** 항목 간의 선후 관계나 **순서가 상관없는 목록**을 나열할 때 사용합니다.
*   **특징:** 각 항목 앞에 까만 점(●, 불릿 기호)이 자동으로 생성됩니다.

###  `<ol>` (Ordered List)
*   **개념:** 인과관계, 시간 순서, 우선순위 등 **순서가 중요한 목록**을 표시할 때 사용합니다.
*   **특징:** 숫자가 자동으로 매겨지며, `type="i"` 속성을 주면 로마자 소문자(`i`, `ii`, `iii`) 등으로 번호를 바꿀 수 있습니다.

###  `<li>` (List Item)
*   **개념:** `<ul>`이나 `<ol>` 내부에서 **실제 데이터 항목 하나하나를 나타내는 단독 태그**입니다.
*   **주의점:** 반드시 부모 태그인 `<ul>` 또는 `<ol>`의 바로 하위에 위치해야 합니다.

 **목록 실습 예제:**
```html
<!-- 순서 없는 목록 (기본 프로필) -->
<ul>
    <li>이름: 신혜원</li>
    <li>성별: 여자</li>
</ul>

<!-- 순서 있는 목록 (취미 순위) -->
<ol type="i">
    <li>취미: 유튜브 시청</li>
    <li>좋아하는 음식: 김치찌개</li>
</ol>
```

## 4. 멀티미디어 및 데이터 입력 태그

###  `<img>` (Image)
*   **개념:** 웹페이지에 **사진, 그림, 아이콘 등의 이미지**를 시각적으로 삽입할 때 사용합니다.
*   **특징:** 닫는 태그가 없는 단독 태그이며, 이미지 파일 경로를 뜻하는 `src` 속성과 이미지를 불러오지 못했을 때 보여줄 대체 텍스트인 `alt` 속성이 필수입니다.

###  `<input>` (Input)
*   **개념:** 사용자로부터 데이터(텍스트, 선택값 등)를 **직접 입력받는 상자**를 생성합니다.
*   **특징:** `type` 속성에 따라 역할이 완전히 달라집니다. (`text`는 일반 글자, `email`은 이메일 양식 검증)

 **입력 및 미디어 실습 예제:**
```html
<!-- 이미지 삽입 -->
<img src="hong_gil_dong.png" alt="프로필 사진" width="200">

<!-- 사용자 데이터 입력창 -->
<form>
    <label for="user-email">이메일:</label>
    <input type="email" id="user-email" placeholder="example@email.com">
    
    <label for="user-name">회사명:</label>
    <input type="text" id="user-name" value="(주)테스트컴퍼니">
</form>
```

---

###  정리 마무리 하며

HTML은 각 역할을 가진 태그들이 계층 구조로 맞물려 작동합니다. 설정을 관리하는 머리(`<head>`), 본문을 담는 몸통(`<body>`) 구조 위에서 텍스트(`<p>`), 리스트(`<ul>`/`<ol>` + `<li>`), 미디어 및 입력 폼(`<img>`, `<input>`)을 조합하면 규격화된 웹 문서(이력서 등)를 자유자재로 설계할 수 있습니다.
